# Sistema de Chamados de TI

Projeto desenvolvido em Python com o objetivo de praticar conceitos de Programação Orientada a Objetos (POO), organização de código e lógica de programação.

## Sobre o projeto

O Sistema de Chamados de TI permite realizar o gerenciamento básico de solicitações de suporte técnico, utilizando classes e objetos para representar os chamados e controlar seus respectivos estados.

## Funcionalidades

- Cadastro de chamados.
- Listagem dos chamados cadastrados.
- Busca de chamados pelo ID.
- Início do atendimento.
- Encerramento do atendimento.
- Controle de status dos chamados.

## Tecnologias utilizadas

- Python 3
- Programação Orientada a Objetos (POO)
- Git e GitHub

## Conceitos praticados

- Classes e objetos.
- Construtores (`__init__`).
- Atributos e métodos.
- Listas de objetos.
- Estruturas condicionais.
- Estruturas de repetição.
- Parâmetros e retornos de funções.
- Tratamento de estados de objetos.

## Como executar

1. Clone este repositório.
2. Acesse a pasta do projeto.
3. (Recomendado) Crie e ative um ambiente virtual:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

4. Execute:

```bash
python main.py
```
